- Three languages:

  - Russian
  - Kyrgyz

- Product catalog
- Product categories
- Product search
- Product sorting
- Price filtering
- Shopping cart
- Favorites
- Product details

- Account demo

- Responsive design
- Animated purple interface
- Gold buttons
- Admin dashboard

## Start

1. Open the TECHZONE folder in Visual Studio Code.
2. Install Live Server.
3. Open index.html.
4. Press Go Live.

## Admin panel

Open:

admin/index.html

The admin panel currently uses browser localStorage.

## Important

This project is a frontend prototype.

For a real online marketplace, connect:

- Backend API
- Database
- Secure administrator authentication
- Customer authentication
- Payment gateway
- Order management
- Product image storage
- Delivery integration
- Real customer support

The generated 1000-product catalog contains demo entries,
not verified supplier inventory.
